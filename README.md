# Evaluating LLMs as Refactoring Reviewers

This repository contains the replication package for an academic study that investigates **how effective Large Language Models (LLMs) are at evaluating code refactorings when compared to human reviewers**. The focus is on assessing whether LLM judgments align with human evaluations when analyzing refactoring changes in real code.

The study considers two common refactoring types:

* **Extract Method**
* **Rename Variable**

The repository includes datasets, LLM outputs, and scripts used to preprocess data and interact with the models.

## Data

### `data/marv-filtered-datase.tsv`

This file contains a filtered version of the **MARV dataset**, restricted to commits that include only the following refactoring types:

* Extract Method
* Rename Variable

This dataset is used as input for the LLM evaluation process. In particular, the following columns are consumed by the prompt defined in `src/classification.py`:

* **Code before**
* **Code after**

These columns represent the code state before and after the refactoring, respectively.

---

### `data/final-dataset.xlsx`

This is the **final dataset used in the analysis**. It aggregates:

* The responses generated by the evaluated LLMs
* The assessments provided by **three human reviewers**
* Additional metadata and analysis fields used in the study

Each row corresponds to a single refactoring instance. The column `id` uniquely identifies each instance and is used to link dataset entries with LLM output files.

---

## Output

The `output/` directory stores the raw textual responses generated by the LLMs.

### General Structure

* The directory contains two subfolders, one for each evaluated prompt configuration.
* Inside each subfolder, each file is named as `{id}.txt`, where `id` matches the corresponding value in the `id` column of `final-dataset.xlsx`.

---

### `output/detailed_prompt/`

Contains LLM outputs for **pilot experiments** conducted using a reduced set of **15 samples**. These experiments were used to refine and validate the prompt design.

---

### `output/final_prompt/`

Contains the complete set of LLM outputs generated using the **final version of the prompt** over all selected refactoring instances.

The evaluated models include:

* **GPT-mini**
* **Llama Scout**

Each `.txt` file corresponds to the raw response produced by a given LLM for a specific refactoring instance.

---

## Source Code

### `src/remove_characters.py`

This script was used during data preprocessing to remove Git diff-specific markers (e.g., `++`, `--`) from the original dataset. The cleaning step ensures that the code snippets provided to the LLMs represent plain source code rather than diff-formatted text.

---

### `src/classification.py`

This script is responsible for:

* Building the prompts used to evaluate refactorings
* Communicating with the LLM APIs
* Submitting the **Code before** and **Code after** snippets
* Collecting and saving the LLM-generated evaluations

The outputs generated by this script are stored as `.txt` files in the corresponding `output/` subdirectories.
